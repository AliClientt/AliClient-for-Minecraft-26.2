## 🇹🇷 Türkçe Kurulum Rehberi

AliClient 26.2 paketini ister bilgisayarda ister mobilde, kullandığın platforma veya istemciye uygun adımı takip ederek kolayca kurabilirsin.

### 📥 1. Adım: Dosyaları İndirme
1. Sitemizdeki veya GitHub sayfamızdaki **"Hemen İndir (.zip)"** butonuna tıklayarak güncel `AliClient` paketini indir ve arşivden çıkart.

### ⚙️ 2. Adım: İstemciye ve Platforma Göre Kurulum

* **Mobil (PojavLauncher / Zalith Launcher / MJ Launcher) Kullanıcıları:**
  1. Telefonundan PojavLauncher, Zalith veya MJ Launcher uygulamasını aç.
  2. Profil ayarlarından uygun sürüm için **Fabric Loader** kurulumunu yap ve oyunu bir kez çalıştır.
  3. İndirdiğin `.zip` arşivindeki mod dosyalarını telefonundaki `.minecraft/mods` klasörüne kopyala (Dosya yöneticisinden `games > pojavlauncher > .minecraft > mods` yolunu takip edebilirsin).
  4. Launcher üzerinden oyunu başlat ve mobil performansın tadını çıkar!

* **Prism Launcher Kullanıcıları:**
  1. Prism Launcher'ı aç ve sol üstteki **"Add Instance"** seçeneğini kullan.
  2. Paket içerisindeki `.mrpack` dosyasını (veya `.zip` arşivini) pencereye sürükleyip bırakarak otomatik kurulumu tamamla.

* **Lunar Client / Feather Client / Badlion Kullanıcıları:**
  1. İstemcini aç ve profil ayarlarından **Fabric** sürümünü seç.
  2. Çıkarttığın klasördeki optimizasyon modlarını (`.jar` dosyalarını) ilgili istemcinin mod dizinine (`mods` klasörüne) at.

* **Klasik Minecraft Launcher (PC Fabric) Kullanıcıları:**
  1. Minecraft Launcher üzerinden doğru sürümün **Fabric Loader** profilini seç.
  2. Mod dosyalarını `.minecraft/mods` dizinine kopyala ve **Sodium** ile **Iris** ayarlarının aktif olduğunu kontrol et.

## 🇬🇧 English Installation Guide

Follow these steps based on the client or platform you use to install AliClient 26.2 and unlock ultimate performance.

### 📥 Step 1: Download the Files
1. Click the **"Download Now (.zip)"** button on our website or repository to download the latest package.

### ⚙️ Step 2: Setup by Platform & Client

* **Mobile (PojavLauncher / Zalith Launcher / MJ Launcher) Users:**
  1. Open PojavLauncher, Zalith, or MJ Launcher on your mobile device.
  2. Install and select the **Fabric Loader** profile for the appropriate version, then launch the game once.
  3. Copy the mod files from the downloaded `.zip` archive into your mobile `.minecraft/mods` directory (usually found via file manager at `games > pojavlauncher > .minecraft > mods`).
  4. Launch the game through your mobile launcher and enjoy smooth performance!

* **Prism Launcher Users:**
  1. Open Prism Launcher and use the import option or drag and drop the `.mrpack` (or `.zip`) file directly into the launcher window to configure the instance.

* **Lunar Client / Feather Client / Badlion Users:**
  1. Open your launcher and select the **Fabric** version in your profile settings.
  2. Place the optimized mod files (`.jar` files) from the extracted folder into your client's mod directory (`mods` folder).

* **Classic Minecraft Launcher (PC Fabric) Users:**
  1. Select the correct **Fabric Loader** profile via the Minecraft Launcher.
  2. Copy the mod files into your `.minecraft/mods` directory and verify **Sodium** & **Iris** settings.
